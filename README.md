# GRAYKO TOYS — E-Commerce Dropshipping Platform 🧸🏎️

Сучасна повнофункціональна e-commerce платформа дитячих іграшок з підтримкою дропшипінгу, синхронізацією XML/YML фідів, роздільними відправленнями зі складів постачальників, контролем РРЦ (RRP) та автоматичною генерацією ТТН Нової Пошти.

---

## 🌟 Можливості та функції

### 🛍️ Вітрина магазину (Storefront)
- **Повний асортимент іграшок**:
  - Машинки та всюдиходи на радіокеруванні (4WD RC, дрифт, браслети жестів, автотреки).
  - Ляльки та інтерактивні пупси з аксесуарами, плюшеві м'які іграшки.
  - Дерев'яні 3D-конструктори та механічні моделі (Ugears, Wood Trick).
  - Екологічні дерев'яні та Монтессорі іграшки (Cubika).
  - STEM-набори, фізичні та гідравлічні досліди (4M KidzLabs).
  - Настільні ігри та логічні головоломки (Smart Games).
  - Творчість, ліплення та кінетичний пісок.
  - Сюжетно-рольові ігрові набори (дитячі кухні з водою і парою).
  - Іграшки для немовлят (0–12 міс.) та активні ігри/самокати для вулиці.
- **Багаторівневі фасетні фільтри**:
  - Підбір за віком (`0–1`, `1–3`, `3–5`, `6–8`, `9–12`, `14+`), категоріями, матеріалами, брендами та ціновим діапазоном.
- **Швидкий пошук** з миттєвим автодоповненням та підказками.
- **Модальні вікна швидкого перегляду** з галереєю, характеристиками та розумними супутніми товарами (крос-сейл).

### 📦 Роздільні відправлення та Логістика
- **Multi-Warehouse Split Orders**: Автоматичний поділ замовлення на окремі посилки за складами відвантаження (Київ, Бердичів) з розрахунком доставки та правил пакування.
- **Нова Пошта 2.0**:
  - Живий пошук міст України, відділень та поштоматів.
  - Автоматична генерація 14-значних номерів **ТТН** для кожної посилки.
  - Генерація та друк **стікерів Експрес-накладних** зі штрихкодами (`/api/shipments/<id>/sticker`).
  - Симуляція фіскальних чеків (Checkbox).

### ⚙️ Кабінет керування дропшипінгом (`/admin`)
- **Приватний доступ**: доступний виключно за посиланням `/admin` без публічних точок входу на сайті.
- **Синхронізація фідів**:
  - **Fast Sync (1–2 год.)**: оновлення залишків та цін з автоматичним контролем РРЦ.
  - **Full Sync (Нічний)**: повне оновлення описів, характеристик та фото.
- **Суворий захист від демпінгу (RRP Enforcement Rule)**: блокування встановлення ціни нижче рекомендованої постачальником на рівні бекенду (HTTP 400).
- **Диспетчер замовлень**: журнал замовлень із номерами ТТН та прямими посиланнями на друк накладних.

## 🏗️ Архітектура проєкту

```
grayko/
├── backend/
│   ├── db.py               # SQLite схема та підключення до БД
│   ├── dropship_feed.py    # Парсер/генератор B2B XML/YML фідів та RRP валідатор
│   ├── logistics.py        # Емуляція Нової Пошти, генерація ТТН та стікерів
│   └── server.py           # Multi-threaded REST API та роутинг
├── frontend/
│   ├── index.html          # Публічна вітрина магазину
│   ├── admin.html          # Приватна панель керування дропшипінгом (/admin)
│   ├── css/
│   │   ├── index.css       # Дизайн-система, токени та типографіка
│   │   └── components.css  # Стилі компонентів, карток, кошика та чекауту
│   └── js/
│       ├── api.js          # REST API клієнт
│       ├── state.js        # Реактивне сховище стану та кошика
│       ├── app.js          # Головний контролер вітрини
│       ├── admin.js        # Контролер панелі керування (/admin)
│       └── components/     # Модульні UI компоненти
├── data/
│   └── b2b_feed.xml        # Згенерований XML фід каталогу
└── docs/
    └── technical-raw.md    # Технічна специфікація та регламент дропшипінгу
```

## 🚀 Запуск проєкту локально

### 1. Вимоги
- Python 3.10+ (стандартна бібліотека, додаткові зовнішні пакети не потрібні)

### 2. Запуск сервера
```bash
python backend/server.py
```

### 3. Доступ у браузері
* **Вітрина інтернет-магазину:** [http://localhost:8077/](http://localhost:8077/) (або `http://localhost:8000/`)
* **Панель керування дропшипінгом:** [http://localhost:8077/admin](http://localhost:8077/admin)
